# Portfolio project prototypes

This branch holds source linked from Jim Halafihi's portfolio project cards. Each folder translates its displayed design brief into a small, inspectable proof of concept. The Underwater Cleanup folder includes the complete Pygame reference implementation; the live portfolio contains an equivalent browser-playable React version.

## Projects
- Responsible AI choice checker
- The Moss Boss service estimator
- Underwater Cleanup Pygame
- AI capability pathway
- Usability test board
- Career evidence tracker
- Sports Monte Carlo model
